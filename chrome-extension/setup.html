CONFIGURATION REQUISE

Chrome ne fait pas encore confiance à EcoData

Le certificat racine doit être installé une seule fois pour permettre l’optimisation des sites HTTPS.

Télécharger le certificat EcoData
  1. Téléchargez le certificat avec le bouton ci-dessus.
  2. Copiez puis ouvrez cette adresse dans un nouvel onglet :chrome://certificate-manager/localcerts/usercerts
  3. Cliquez sur Importer, sélectionnez ecodata-ca.pem, puis confirmez.
  4. Fermez et relancez Chrome, reconnectez EcoData, puis rechargez le site.

Installez uniquement un certificat provenant de votre propre serveur EcoData ou d’un administrateur de confiance.
